# كابتن أيتوس

تطبيق أندرويد خاص بسائق واحد: بيقرا كروت طلبات إن درايف وديدي وأوبر ويعرض حكم فوري (اقبله / راجع / فكّر / ارفضه) حسب قواعدك وصافي ربحك.

- القراءة: نص الشاشة (Accessibility) + لقطة شاشة بتتقرا بالـ OCR (Google ML Kit) جوه الموبايل. اللقطة بتتمسح فوراً.
- التطبيق للقراءة والحكم فقط، مبيضغطش ولا بيقبل ولا بيرفض.
- الواجهة عربي بالكامل، ووضعين نهاري/ليلي.
- البناء: GitHub Actions (`.github/workflows/build.yml`) بيطلّع APK debug في Artifacts بعد كل push.

الصلاحيات المطلوبة بعد التثبيت: خدمة الوصول، الظهور فوق التطبيقات، الإشعارات، واستثناء البطارية (من "المزيد ← معالج الإعداد").
